# kubectl apply view-last-applied

View the latest last-applied-configuration annotations by type/name or file. The default output will be printed to stdout in YAML format. You can use the -o option to change the output format.

```
kubectl apply view-last-applied (TYPE [NAME | -l label] | TYPE/NAME | -f FILENAME)
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --all |  | bool |  | Select all resources in the namespace of the specified resource types |
| --filename | -f | strings |  | Filename, directory, or URL to files that contains the last-applied-configuration annotations |
| --help | -h | bool |  | help for view-last-applied |
| --kustomize | -k | string |  | Process the kustomization directory. This flag can't be used together with -f or -R. |
| --output | -o | string | "yaml" | Output format. Must be one of (yaml, json) |
| --recursive | -R | bool |  | Process the directory used in -f, --filename recursively. Useful when you want to manage related manifests organized within the same directory. |
| --selector | -l | string |  | Selector (label query) to filter on, supports '=', '==', '!=', 'in', 'notin'.(e.g. -l key1=value1,key2=value2,key3 in (value3)). Matching objects must satisfy all of the specified label constraints. |
