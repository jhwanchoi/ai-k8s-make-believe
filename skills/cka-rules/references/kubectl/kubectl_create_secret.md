# kubectl create secret

Create a secret with specified type. A docker-registry type secret is for accessing a container registry. A generic type secret indicate an Opaque secret type. A tls type secret holds TLS certificate and its associated key.

```
kubectl create secret (docker-registry | generic | tls)
```

하위 명령: docker-registry, generic, tls
