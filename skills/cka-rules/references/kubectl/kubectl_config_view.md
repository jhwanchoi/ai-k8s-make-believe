# kubectl config view

Display merged kubeconfig settings or a specified kubeconfig file. You can use --output jsonpath={...} to extract specific values using a jsonpath expression.

```
kubectl config view [flags]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --allow-missing-template-keys |  | bool | true | If true, ignore any errors in templates when a field or map key is missing in the template. Only applies to golang and jsonpath output formats. |
| --flatten |  | bool |  | Flatten the resulting kubeconfig file into self-contained output (useful for creating portable kubeconfig files) |
| --help | -h | bool |  | help for view |
| --merge |  | tristate[=true] | true | Merge the full hierarchy of kubeconfig files |
| --minify |  | bool |  | Remove all information not used by current-context from the output |
| --output | -o | string | "yaml" | Output format. One of: (json, yaml, kyaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file). |
| --raw |  | bool |  | Display raw byte data and sensitive data |
| --show-managed-fields |  | bool |  | If true, keep the managedFields when printing objects in JSON or YAML format. |
| --template |  | string |  | Template string or path to template file to use when -o=go-template, -o=go-template-file. The template format is golang templates [http://golang.org/pkg/text/template/#pkg-overview]. |
