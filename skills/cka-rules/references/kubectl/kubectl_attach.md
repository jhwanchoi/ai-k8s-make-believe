# kubectl attach

Attach to a process that is already running inside an existing container.

```
kubectl attach (POD | TYPE/NAME) -c CONTAINER
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --container | -c | string |  | Container name. If omitted, use the kubectl.kubernetes.io/default-container annotation for selecting the container to be attached or the first container in the pod will be chosen |
| --detach-keys |  | string | "ctrl-p,ctrl-q" | Override the key sequence for detaching a container |
| --help | -h | bool |  | help for attach |
| --pod-running-timeout |  | duration | 1m0s | The length of time (like 5s, 2m, or 3h, higher than zero) to wait until at least one pod is running |
| --quiet | -q | bool |  | Only print output from the remote session |
| --stdin | -i | bool |  | Pass stdin to the container |
| --tty | -t | bool |  | Stdin is a TTY |
