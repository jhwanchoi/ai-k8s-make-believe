# kubectl patch

Update fields of a resource using strategic merge patch, a JSON merge patch, or a JSON patch. JSON and YAML formats are accepted. Note: Strategic merge patch is not supported for custom resources.

```
kubectl patch (-f FILENAME | TYPE NAME) [-p PATCH|--patch-file FILE]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --allow-missing-template-keys |  | bool | true | If true, ignore any errors in templates when a field or map key is missing in the template. Only applies to golang and jsonpath output formats. |
| --dry-run |  | string[="unchanged"] | "none" | Must be "none", "server", or "client". If client strategy, only print the object that would be sent, without sending it. If server strategy, submit server-side request without persisting the resource. |
| --field-manager |  | string | "kubectl-patch" | Name of the manager used to track field ownership. |
| --filename | -f | strings |  | Filename, directory, or URL to files identifying the resource to update |
| --help | -h | bool |  | help for patch |
| --kustomize | -k | string |  | Process the kustomization directory. This flag can't be used together with -f or -R. |
| --local |  | bool |  | If true, patch will operate on the content of the file, not the server-side resource. |
| --output | -o | string |  | Output format. One of: (json, yaml, kyaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file). |
| --patch | -p | string |  | The patch to be applied to the resource JSON file. |
| --patch-file |  | string |  | A file containing a patch to be applied to the resource. |
| --recursive | -R | bool |  | Process the directory used in -f, --filename recursively. Useful when you want to manage related manifests organized within the same directory. |
| --show-managed-fields |  | bool |  | If true, keep the managedFields when printing objects in JSON or YAML format. |
| --subresource |  | string |  | If specified, patch will operate on the subresource of the requested object. |
| --template |  | string |  | Template string or path to template file to use when -o=go-template, -o=go-template-file. The template format is golang templates [http://golang.org/pkg/text/template/#pkg-overview]. |
| --type |  | string | "strategic" | The type of patch being provided; one of [json merge strategic] |
