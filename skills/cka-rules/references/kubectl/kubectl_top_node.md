# kubectl top node

Display resource (CPU/memory) usage of nodes. The top-node command allows you to see the resource consumption of nodes.

```
kubectl top node [NAME | -l label]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --help | -h | bool |  | help for node |
| --no-headers |  | bool |  | If present, print output without headers |
| --selector | -l | string |  | Selector (label query) to filter on, supports '=', '==', '!=', 'in', 'notin'.(e.g. -l key1=value1,key2=value2,key3 in (value3)). Matching objects must satisfy all of the specified label constraints. |
| --show-capacity |  | bool |  | Print node resources based on Capacity instead of Allocatable(default) of the nodes. |
| --show-swap |  | bool |  | Print node resources related to swap memory. |
| --sort-by |  | string |  | If non-empty, sort nodes list using specified field. The field can be either 'cpu' or 'memory'. |
| --use-protocol-buffers |  | bool | true | Enables using protocol-buffers to access Metrics API. |
