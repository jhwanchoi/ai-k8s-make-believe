# kubectl version

Print the client and server version information for the current context.

```
kubectl version [flags]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --client |  | bool |  | If true, shows client version only (no server required). |
| --help | -h | bool |  | help for version |
| --output | -o | string |  | One of 'yaml' or 'json'. |

전역 플래그(--namespace, --context 등)는 kubectl.md 참고.
