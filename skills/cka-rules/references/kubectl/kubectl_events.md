# kubectl events

Display events. Prints a table of the most important information about events. You can request events for a namespace, for all namespace, or filtered to only those pertaining to a specified resource.

```
kubectl events [(-o|--output=)json|yaml|kyaml|name|go-template|go-template-file|template|templatefile|jsonpath|jsonpath-as-json|jsonpath-file] [--for TYPE/NAME] [--watch] [--types=Normal,Warning]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --all-namespaces | -A | bool |  | If present, list the requested object(s) across all namespaces. Namespace in current context is ignored even if specified with --namespace. |
| --allow-missing-template-keys |  | bool | true | If true, ignore any errors in templates when a field or map key is missing in the template. Only applies to golang and jsonpath output formats. |
| --chunk-size |  | int | 500 | Return large lists in chunks rather than all at once. Pass 0 to disable. |
| --for |  | string |  | Filter events to only those pertaining to the specified resource. |
| --help | -h | bool |  | help for events |
| --no-headers |  | bool |  | When using the default output format, don't print headers. |
| --output | -o | string |  | Output format. One of: (json, yaml, kyaml, name, go-template, go-template-file, template, templatefile, jsonpath, jsonpath-as-json, jsonpath-file). |
| --show-managed-fields |  | bool |  | If true, keep the managedFields when printing objects in JSON or YAML format. |
| --template |  | string |  | Template string or path to template file to use when -o=go-template, -o=go-template-file. The template format is golang templates [http://golang.org/pkg/text/template/#pkg-overview]. |
| --types |  | strings |  | Output only events of given types. |
| --watch | -w | bool |  | After listing the requested events, watch for more events. |
