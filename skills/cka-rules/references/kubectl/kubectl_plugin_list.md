# kubectl plugin list

List all available plugin files on a user's PATH. To see plugins binary names without the full path use --name-only flag. Available plugin files are those that are: - executable - anywhere on the user's PATH - begin with "kubectl-"

```
kubectl plugin list [flags]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --help | -h | bool |  | help for list |
| --name-only |  | bool |  | If true, display only the binary name of each plugin, rather than its full path |

전역 플래그(--namespace, --context 등)는 kubectl.md 참고.
