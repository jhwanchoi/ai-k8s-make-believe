# kubectl config set-context

Set a context entry in kubeconfig. Specifying a name that already exists will merge new fields on top of existing values for those fields.

```
kubectl config set-context [NAME | --current] [--cluster=cluster_nickname] [--user=user_nickname] [--namespace=namespace]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --cluster |  | string |  | cluster for the context entry in kubeconfig |
| --current |  | bool |  | Modify the current context |
| --help | -h | bool |  | help for set-context |
| --namespace | -n | string |  | namespace for the context entry in kubeconfig |
| --user |  | string |  | user for the context entry in kubeconfig |

전역 플래그(--namespace, --context 등)는 kubectl.md 참고.
