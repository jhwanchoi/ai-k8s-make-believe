# kubectl config get-contexts

Display one or many contexts from the kubeconfig file.

```
kubectl config get-contexts [(-o|--output=)name)]
```

| flag | short | type | default | description |
|---|---|---|---|---|
| --help | -h | bool |  | help for get-contexts |
| --no-headers |  | bool |  | When using the default or custom-column output format, don't print headers (default print headers). |
| --output | -o | string |  | Output format. One of: (name). |
